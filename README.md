# Python Encoder Web

Trang web tĩnh giúp mã hóa đoạn mã Python thành một file `.py` tự giải mã. Dữ liệu chạy hoàn toàn ở phía client, nên có thể deploy miễn phí trên GitHub Pages.

## Cách chạy miễn phí trên GitHub Pages

1. Tạo một repository mới trên GitHub.
2. Upload các file trong thư mục này vào repository.
3. Vào Settings → Pages.
4. Chọn Branch: `main` và Folder: `/root`.
5. Lưu lại và chờ GitHub Pages build xong.
6. Mở URL được cung cấp, ví dụ: `https://yourname.github.io/your-repo/`.

## Tệp chính

- `index.html`: giao diện trang web
- `styles.css`: giao diện đẹp và responsive
- `main.js`: logic mã hóa Python

## Ghi chú

- Đây là mẫu học tập, không nên dùng cho mục tiêu vi phạm pháp luật hoặc bảo mật.
- Nếu muốn tự động deploy mỗi khi push code, có thể dùng workflow trong `.github/workflows/deploy.yml`.
